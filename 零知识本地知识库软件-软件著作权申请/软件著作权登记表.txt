软件主要功能与创新点
──────────────────────────────────────────────────

一、主要功能

1. 零知识加密知识库
   用户设置主密码创建保险库；文档在写入磁盘/数据库前于浏览器（或 CLI
   进程）内完成加密，任何存储介质与服务器均无法读取文档内容。

2. 文档管理
   支持文档的创建、编辑、删除、列表浏览与按标题检索；文档采用块
   （Block）模型（标题、正文、代码、引用、表格等），可无损导出为
   Markdown 文本。

3. 全文检索
   基于本地内存 FTS5 索引实现全库关键词检索；索引仅存于内存，关闭
   保险库后即销毁，不落盘、无明文残留。

4. 离线备份与恢复
   一键导出 .kb 备份文件（仅含密文）；支持在另一台机器或全新环境
   以相同主密码导入恢复全部数据；全新环境可在锁定页“从 .kb 备份
   恢复”直接以备份建立知识库并恢复，无需先手动创建。

5. 离线同步（密文同步磁带）
   通过携带 .kbsync 文件在两个共享同一工作区的机器间同步文档，
   采用按文档 ID 的 LWW（最新写入胜出）收敛规则，支持删除的
   墓碑（Tombstone）传播；全程仅传输密文。

6. Markdown 编辑与实时预览
   内置无第三方依赖、防 XSS 的 Markdown 渲染器；支持标题、段落、
   引用、代码块、列表与管道表格；编辑与预览可切换，未保存修改
   有离开提醒，支持 Ctrl/Cmd+S 快捷保存。

7. 修改主密码（重设密钥）
   可在不丢失数据的前提下将整个保险库的所有文档密钥在新主密码下
   重新封装（Re-Key），旧密码即刻失效，全程不落盘任何明文。

二、创新点

1. “零知识 + 本地优先”双隐私架构：数据加密完全在本机完成，服务
   端（如为演示部署的仅静态文件服务器）仅提供文件传输，无法接触
   任何明文。
2. 主密码 — 工作区密钥（PBKDF2-SHA256 310,000 迭代 + HKDF-SHA256
   命名空间派生）— 每文档 DEK（AES-256-GCM 随机密钥）三级密钥
   分层：单个文档密钥泄露不影响其他文档，工作区之间密钥隔离。
3. 全文检索索引“仅内存不落盘”设计：在加密数据库之上重建明文
   索引，兼顾检索体验与隐私。
4. 密文同步磁带：仅携带密文与时间戳的同步协议，跨设备收敛一致，
   且删除语义可正确传播而不复活旧文档。
5. 去第三方依赖：核心库与 Web 客户端全部原生实现，攻击面最小。
